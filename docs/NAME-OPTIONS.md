# Brand name options

The public site currently uses **Northlight** as a working name. It lives in `js/brand.js` (`window.BRAND.name`). HTML still says Northlight so the no-JS and crawler fallbacks match. None of these names is final.

## Northlight

Midwest nights and the Chicago skyline after dark. It works for a wedding ballroom and a late festival load-in without sounding like a nightclub-only brand, so quinceañeras, park events, and block parties still fit.

## Lumen Line

Light, a line of sight, and a quiet echo of Brickline (Khaled’s lead software). It sounds like a studio and a tool, which helps if the vendor waitlist becomes half the business.

## Gatherwell

Host-first and plainspoken. It reads as trustworthy for family events — weddings, quinceañeras, birthdays, block parties — and puts the person planning the night ahead of the vendor software.
